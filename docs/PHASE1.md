검증: `npm test` 23개 통과, `npm run build` 통과, Playwright 2개 시나리오 통과(실제 AI 대전 1판 포함), `npm audit` 취약점 0개. 자동 플레이는 조준 해법으로 실제 UI를 조작했으며 HP·피해·턴을 강제로 바꾸지 않았음.

Phase 2에서 개선할 부분:

1. 고각 포탄은 화면 상단을 벗어나면 위치 안내만 표시됨. 부드러운 카메라 추적 필요.
2. 포탄의 실제 효과는 구별되지만 폭발 렌더링은 원형 섬광 중심이고 소리도 유사함. 단계별 폭발과 전용 파티클/음향 필요.
3. 파괴된 지면에도 잔디가 다시 그려짐. 원본 지형과 비교해 노출 흙/착탄 흔적 표현 필요.
4. 직접 명중 텍스트는 있지만 비행 직후 피격 순간을 강조할 짧은 정지·동적 연출이 부족함.
5. AI의 특수탄 선택은 확률 중심임. 지형 경사·체력 기반 전술로 개선할 여지.
6. 승패 UI는 완성했지만 차량 승리/파괴 동작과 승리 파티클은 부족함.

정상적인 물리/높이 필드/턴 상태 머신을 유지한 채 위 항목을 개선한다. 재미와 2~3분 경기 시간은 자동화 결과만으로 확정하지 않는다.
