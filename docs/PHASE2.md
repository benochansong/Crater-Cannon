# Phase 2 — EXPLOSIVE BATTLE 완료 보고

## 1. 기존 상태와 발견한 문제

Phase 1 커밋 `be06aae`에 완성된 2대의 차량, 각도/세기/드래그, 바람 탄도, 3종 포탄, 파괴 지형, 차량 정착, AI/턴/승패/재대결을 먼저 검증하고 보존했다. 분류는 [Phase 1 인계](PHASE1.md)에 기록했다.

고각 포탄의 화면 이탈, 서로 비슷한 원형 폭발과 소리, 파괴면에 다시 생성되는 잔디, 확률에 치우친 AI 특수탄 선택을 개선 대상으로 정했다. 첫 테스트에서 1픽셀 지형 충돌 누락을 발견해 Phase 1에서 수정했고, Phase 2에서는 키보드 조준 수치 즉시 갱신과 카메라 축소 시 지형 가장자리 빈 공간도 수정했다.

## 2. 실제 개선 기능

기존 1/120초 물리와 턴 상태 머신을 유지했다. 별도 Camera 모듈을 추가하고, 드래그를 카메라의 역변환 좌표로 계산한다. UI는 한국어이며 단축키, 탄약 제한, 설정 일시정지, 최근 20경기, 첫 발사 튜토리얼을 유지했다.

## 3. 발사와 폭발

방향에 맞는 순간 화염, 포신 반동과 회복, 차체 반응, 속도 잔상, 비행 휘파람과 좌우 패닝을 구현했다. 고각 비행에서는 부드럽게 축소해 포탄과 두 차량을 함께 보여 주고, HUD는 고정한다.

기본탄은 불꽃 덩어리/밝은 코어/연기, 크레이터탄은 큰 흙먼지/무거운 파편/낮은 파열음, 충격파탄은 다중 동심원/전기 선/빠르게 하강하는 전자음을 사용한다. 섬광→팽창→노출 지면→잔여 연기/피해 표시를 같은 충돌점에서 처리한다.

직접 명중에는 `DIRECT HIT!`, 큰 실제 피해 숫자, 추가 타격음, 강한 짧은 흔들림과 55ms 정지를 적용했다. 일반 충돌 정지는 22ms이다. 실제 탄도나 피해를 조작하지 않는다. 승리에는 별 애니메이션/축하 입자/차량 움직임, 패배 차량에는 어두운 외형과 연기가 적용된다.

## 4. 지형 파괴

원본 높이 필드를 보존해 잔디 표면과 노출된 흙의 가장자리를 구분한다. 반복 포격, 기반암 한계, 폭발 후 중력 정착과 충격파 밀림은 기존 물리 구조를 유지한다. 직접 화력/넓은 지형 파괴/차량 이동의 결과가 다르다.

## 5. AI와 밸런스

플레이어와 같은 발사·중력·바람·충돌 함수로 해법을 탐색한다. 쉬움은 기본탄과 큰 오차, 보통은 중간 오차와 조건부 특수탄, 어려움은 작은 오차와 경사/지형 높이/남은 체력 기반 특수탄을 사용한다. 마무리 가능한 적이나 자기 체력이 매우 낮으면 기본탄을 우선하며, 경사에는 충격파, 파낼 여지가 큰 지형에는 크레이터탄을 고려한다.

난이도별 오차 폭은 각도 11/5.5/2.4도 범위(중심에서 ±절반), 세기는 그 폭의 1.5배이다. 플레이어의 체력에 따른 숨겨진 명중 보정은 없다. AI 조준 연출 0.8초, 기본 폭발 처리 0.85초 뒤 차량 정착을 확인한다.

## 7. 빌드 및 자동 테스트

2026-11-22 Windows / Node.js 24.14.0에서 실행했다.

- `npm run build`: TypeScript 및 Vite 프로덕션 빌드 통과.
- `npm test`: 2개 파일, **32개 테스트 통과**. 기존 23개 테스트를 유지했다.
- `npm run test:e2e`: Firefox **5개 시나리오 통과**. 세 난이도 각 한 판을 포함한다.
- 시각 수정 후 `npm run test:e2e -- --grep 'high arcs|settings persist'`: 해당 **2개 회귀 시나리오 재통과**. 추가로 1366×768에서 발사 패널이 첫 화면 안에 들어오는지 확인하는 **1개 PC 화면 테스트 통과**(현재 브라우저 테스트 총 6개).
- `npm run test:smoke`: 프로덕션 메뉴→발사→AI 턴 통과. 브라우저 오류/외부 요청 0, QA 브리지 없음.
- `npm audit`: 개발 의존성을 포함해 **취약점 0개**.
- 파티클 최대 240개, 지형 변경 시에만 Canvas 캐시 재생성, 종료된 효과 제거, 재대결 시 렌더러/카메라 새로 생성. 오디오 노드는 종료 시 연결 해제한다.

## 9. 한계와 미해결 사항

확인된 진행 불가 오류는 없다. 다만 자동 조준의 28~31초 경기는 사람이 각도를 고민하는 2~3분 목표 경기의 검증이 아니며, 자동 테스트만으로 재미나 전체 난이도 균형을 확정하지 않았다. 모든 PC에서 일정 FPS를 보장하는 하드웨어 성능 측정은 하지 않았다. 브라우저 검증은 Windows와 GitHub Actions Ubuntu의 Firefox이며 다른 브라우저의 실제 청감은 별도로 평가하지 않았다.

PC 우선 게임이며 모바일에서는 화면이 작다. 높이 필드는 동굴/오버행을 지원하지 않는다. 아주 높은 포탄을 따라갈 때 차량이 작아지는 것은 두 차량과 포탄을 동시에 유지하기 위한 선택이다. 온라인 대전, 추가 경기장/차량/무기, 상점, 계정은 요청 범위에 따라 제외했다.

## 10. 직접 플레이할 때 볼 점

`Start-Game.cmd`를 실행하거나 `npm run dev`로 시작한다. 첫 30초 안에 각도·세기·바람을 보고 한 발을 쏠 수 있는지, 빗나간 다음 보정이 자연스러운지, 직접 명중과 범위 피해의 차이가 느껴지는지 확인한다. 같은 지점에 크레이터탄 두 발, 차량 가까이 충격파탄을 사용해 지형과 위치 변화를 비교한다. 쉬움부터 3~5판 플레이하면서 실제 경기 시간과 공정성을 평가할 수 있다.

향후 개선 후보는 실플레이 자료에 기반한 조준 오차·피해량 미세 조정과 브라우저/기기별 렌더링 최적화이다. 이번 버전은 현재 전투 경험을 우선해 여기까지 완성했다.
